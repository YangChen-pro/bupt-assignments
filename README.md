## 推荐资源

### BYR Docs：北邮同学的资料站

[BYR Docs](https://byrdocs.org/) 是面向北邮同学的学习资料平台，提供教材、课程资料、历年试题与复习材料等内容的检索与获取入口。课程学习、考前复习或寻找参考资料时，值得优先看看。

> 使用资料时请尊重原作者与课程方的版权，并遵守学校的学术诚信要求。

### 本科毕业论文 LaTeX 模板

对于熟悉 LaTeX 的同学，推荐使用 [BUPTBachelorThesis Template](https://github.com/BYRIO/BUPTBachelorThesis)。

这套北邮本科毕业论文 LaTeX 模板可以减少排版上的重复工作，把更多时间留给论文内容本身。感谢该模板项目的所有贡献者。
